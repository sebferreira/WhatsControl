# 💬 WhatsControl — WhatsApp CRM & Automation Platform

A fullstack WhatsApp CRM tool that lets businesses manage customer conversations, automate responses with chatbots, and handle live agent handovers — all in real time.


🔗 **Link without access:** [whatscontrol.vercel.app](https://whatscontrol.vercel.app)

---

## ➕ User register
Access is managed by the administrator. There is no public registration — agents are created and managed from the admin panel.

---

## ✨ Features

- 🤖 **Chatbot automation** — Automatically collect and store contact data from incoming WhatsApp messages
- 👥 **Multi-agent support** — Multiple agents can handle conversations simultaneously
- 🔁 **Live agent handover** — Seamlessly transfer a conversation from bot to human agent
- ⚡ **Real-time updates** — Socket.io integration keeps the dashboard in sync instantly
- 🗃️ **Contact management** — Save and organize leads and customers from WhatsApp conversations
- 📊 **Dashboard** — React-powered interface to monitor and manage all active conversations

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React, Vite |
| Backend | Node.js, Express |
| WhatsApp | whatsapp-web.js |
| Real-time | Socket.io |
| Database | PostgreSQL |
| Deployment | Vercel (frontend) |
